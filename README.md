# PSEB Atomcamp Bootcamp

Collaborative learning repository for our Atomcamp journey.

## Learning Areas

- Python 
- NumPy and Pandas
- Machine Learning
- Deep Learning
- Computer Vision
- Software Engineering

## Collaboration Rules

1. Never work directly on main.
2. Create a separate branch for each task.
3. Write meaningful commit messages.
4. Test your code before pushing.
5. Open a Pull Request for review.
6. Keep datasets, model weights and secrets out of Git.

Let's learn, build and collaborate!
